# MY TOMB RAIDER CORNER

**My Tomb Raider Corner** es una página web creada como proyecto de aprendizaje y, al mismo tiempo, como una forma de compartir mi pasión por la saga **Tomb Raider**.

Además de poner en práctica los conocimientos adquiridos durante mi formación en desarrollo web. Aún tengo que reforzar conocimientos, especialmente en **JavaScript**, así que, aunque no lo considero lo ideal, me apoyo de herramientas de IA para que me ayude con la programación.

Para simplificar el despliegue y evitar mantener un backend independiente, la aplicación está desarrollada íntegramente en **Frontend**. Toda la información se obtiene mediante archivos **JSON** locales utilizando la **Fetch API**, simulando el consumo de una API.

## Tecnologías utilizadas

- **HTML5** – Estructura semántica de la aplicación.
- **SCSS (Sass)** – Organización de estilos mediante archivos parciales y diseño responsive.
- **JavaScript (ES6+)** – Lógica de la aplicación y manipulación de datos.
- **React** – Desarrollo de la interfaz mediante componentes reutilizables.
- **React Router** – Navegación entre páginas y rutas dinámicas para galerías y artículos.
- **React Hooks** (`useState`, `useEffect`, `useNavigate`, `useParams`) – Gestión del estado, efectos y navegación.
- **Fetch API** – Obtención de los datos desde archivos JSON.
- **JSON** – Almacenamiento de la información de la galería y los artículos.
- **Vite** – Entorno de desarrollo y herramienta de construcción del proyecto.
- **Git** – Control de versiones.
- **GitHub** – Repositorio del código fuente.
- **GitHub Pages** – Despliegue y alojamiento de la aplicación.

## Características

- Navegación entre páginas sin recarga gracias a React Router.
- Galería de imágenes con vista detallada.
- Artículos organizados por categorías.
- Contenido cargado dinámicamente desde archivos JSON.
- Diseño responsive adaptado a distintos tamaños de pantalla.
- Proyecto desplegado en GitHub Pages.
